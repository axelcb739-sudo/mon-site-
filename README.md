# Carte Nexus – Boutique TCG

Site vitrine d'une boutique de cartes à collectionner (Pokémon, One Piece, Yu-Gi-Oh!, Magic, Lorcana, Dragon Ball, accessoires).

Fonctionnalités : barre d'annonce, menu par univers, recherche, filtres et tri, badges promo / précommande / import JP, gestion du stock, panier latéral (sauvegardé dans le navigateur) avec jauge de livraison offerte, newsletter, responsive mobile.

Ouvrir `index.html` dans un navigateur — aucun build nécessaire.
